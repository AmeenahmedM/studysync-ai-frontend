# StudySync AI Frontend

A simple, production-style React + TypeScript + Vite app for the StudySync AI study and career planner.

## Features

- Landing page
- Login and registration screens
- Protected dashboard routes
- Subject tracking
- Study planner
- Career domain explorer
- AI assistant panel
- Profile page
- Local state persistence for demo usage

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the app:

```bash
npm run dev
```

3. Open the app at:

```bash
http://localhost:5173
```

## Notes

This project is intentionally simplified and uses demo/local data so it can run without a backend service. It is structured so the API layer can be connected later to the Java Spring Boot backend.
